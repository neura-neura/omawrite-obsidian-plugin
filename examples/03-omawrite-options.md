# Omawrite Options Demo

Use this note while exploring the plugin settings. The values below are examples, not metadata consumed by the plugin.

## Writing surface

- **Text size:** adjust the base size used by the editor and preview.
- **Writing width:** choose the approximate character width of each line.
- **Top spacing:** control the breathing room before the first paragraph.
- **Text alignment:** compare left, justified, centered, and right alignment.

## Background and contrast

Select an image from any Windows folder, then move the opacity slider from a subtle value to a stronger one. The preview updates while you adjust the setting, using the same iA Writer Mono S font as the note.

## Interaction

- The normal Omawrite shortcut can be configured in **Settings → Hotkeys**.
- The Omawrite + fullscreen shortcut can also be configured there.
- The top-right control exits Omawrite.
- The bottom-right control toggles native fullscreen.
- The notification switch controls confirmation and error notices.
